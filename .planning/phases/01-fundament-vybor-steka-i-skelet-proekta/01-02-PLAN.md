<objective>
**Как** разработчик, **я хочу** поднять свежий клон репозитория одной командой docker compose up и получить живой health-check и работающую страницу, **чтобы** каждая следующая фаза строилась на проверенном end-to-end скелете (стек уже выбран пользователем — Django, D-01).

Walking Skeleton (TRACER): тонкий, но настоящий end-to-end срез через все слои — Django-проект (config + apps/core) → роутинг (/healthz, /) → реальный read из PostgreSQL + write/read в Redis → SSR-шаблон → gunicorn → Docker-образ → docker-compose с healthchecks. Качество продакшн-уровня: миграции, WhiteNoise, тесты, безопасный health-check. Срез расширяется планами 01-03 (модули) и 01-04 (CI) без архитектурных переделок.
